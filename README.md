# 📊 Supermarket Sales Dashboard (Excel)

## 📌 Overview
This project analyzes supermarket sales data using Excel to generate meaningful business insights and build an interactive dashboard.

---

## 🗂️ Dataset
- ~1,000 transactions  
- Includes: sales, profit, quantity, customer type, payment mode, and date-time data  

---

## 🛠️ Tools & Skills Used
- Microsoft Excel  
- Pivot Tables & Charts  
- Data Cleaning & Transformation  
- Functions:
  - Logical: IF, AND, OR  
  - Arithmetic: SUMIF, AVERAGEIF  
  - Lookup: VLOOKUP, INDEX-MATCH  
  - Date & Text Functions  

---

## 📈 Key Metrics
- 💰 Total Sales: 322,967  
- 📊 Total Profit: 15,379  
- 📦 Total Quantity: 5,510  
- ⭐ Average Rating: 6.97  

---

## 📊 Dashboard Features
- 📌 Sales by Product (Bar Chart)  
- 💳 Payment Mode vs Sales (Bar Chart)  
- 📅 Sales Trend Over Time (Line Chart)  
- 👥 Customer Type Distribution (Pie Chart)  
- 🎯 Interactive Filters (Slicers by Branch & Time)  

---

## 🔍 Key Insights
- ⏰ Peak sales occur around **7 PM (~39,700)**  
- 🏆 Certain product categories drive majority revenue  
- 🌍 Sales patterns vary across different branches
